# 塔科夫 · 任务准备

按地图整理任务物品、钥匙和进图目标，并提供任务悬浮窗与 BTR 路线预测的 Windows 桌面工具。

[1.6.0 版本说明与玩家包](https://github.com/y1751487-ai/TarkovRaidPrep/releases/tag/v1.6.0) · [下载最新玩家版](https://github.com/y1751487-ai/TarkovRaidPrep/releases/latest)

## 1.6.0 更新内容

- 留物清单新增“全部／收藏家／藏身处”筛选，可快速找到对应来源需要保留的物品。
- 物品卡片改为紧凑布局，图片、名称、数量和收集操作集中排列，减少空白；需求来源和备选物品按需展开。
- “收藏家”仅筛选该任务所需物品；“藏身处”筛选未建等级需要的战局中找到材料。
- 筛选只改变显示，数量仍按全部来源合并；同一物品同时用于收藏家和藏身处时，两种筛选均可看到，收集记录共享。
- 保留未保存输入、来源折叠及已备齐置底；当前筛选的需求数和完成数同步更新，无需重置档案。

## 安装与更新

1. 在 Releases 下载名称带 `Player-win-x64.zip` 的玩家包，完整解压到可写文件夹。
2. 打开 `TarkovRaidPrep.exe`。已内置运行时，无需另装 .NET SDK。
3. 首次启动默认创建 PvE 本地档案；若未自动找到游戏日志，在设置中选择 Logs 目录、保存关联并开始监听。
4. 带内置更新的版本会在启动时检查新版本，在“设置 → 程序更新”点击“更新并重启”即可升级。更新验证发布签名与文件摘要，并保留本地档案和设置。

1.5.5 起，程序更新与独立任务资料优先使用固定的 gh-proxy.com 镜像；连接失败、限流或读取超时会自动回退 GitHub，设置中显示当前线路。两条线路都须通过内置公钥签名与文件完整性验证，取消或校验失败时不会自动换线。两路都失败时继续使用现有程序和资料。第三方线路不保证始终可用。

`Source code (zip)` 是 GitHub 自动生成的仓库归档，不是玩家安装包。1.1.10 或更早版本需要先手动升级一次。

## 功能

- 按地图、任务分组查看道具、钥匙、拾取、踩点和战斗目标。
- “设置 → 战局任务悬浮窗”默认开启，监听到新开局后自动显示本图任务，返回大厅后隐藏。悬浮窗置顶且不主动抢焦点，主窗口最小化不影响它；可关闭并从设置重新显示，透明度沿用窗口设置。
- “BTR 跟踪”支持森林、街区、灯塔，结合日志倒计时与参考时刻表预测候选路线；可手动选择地图、校准时间，并按所选路线的站点及经过次数校正进度。
- “跳蚤行情”位于“路线准备”上方，按当前模式搜索中文、英文名称或物品 ID；按 Enter 或点击“搜索物品”提交。星标收藏按模式保存，打开页面或添加收藏时自动查询，可见期间每 10 分钟更新，支持“刷新收藏”。
- 行情详情支持 24 小时／7 天最低参考价走势，按当前模式独立查询。历史数据是离散公开采样，有延迟，不代表逐笔挂单或保证成交价；钥匙仍不能按满次数筛选报价。
- 携带汇总合并本图物品数量，保留钥匙和物品的替代选择。
- 普通物品的寻找与上交分别显示数量及明确的“战局中找到”要求；同一任务中明确等价的一对一寻找/上交目标共享本地收集数量，其他阶段保持独立，寻找或上交数量不计入提前携带汇总。
- “路线准备”支持多张地图排序，合并全路线携带需求并列出每图待办；同一目标跨图只累计一次。
- “非地图任务”位于“主线与 BTR”上方，显示日志进行中或手动规划、且地图页未列出的待办任务；全部已知子目标完成后隐藏，仍可搜索任务名撤销本地进度。每项可展开收起，后台刷新保持折叠，搜索定位自动展开。
- 搜索当前记录中的任务、相关物品和钥匙；输入名称或选择范围后，按 Enter 或点击“搜索”才查询，并可定位到对应地图与任务。
- “任务排序”支持默认、Kappa优先、DSPT优先和手动优先；地图、非地图与路线页面均可用星标标记优先任务。
- “留物清单”包含未接取和已接取未完成任务，只收录明确要求“战局中找到”的上交物品；足量划线并排到底部，多种备选物品默认折叠。
- 留物清单顶部支持“全部／收藏家／藏身处”筛选；按需求来源选出物品，合并总量和收集记录保持共享，展开来源可查看各自需求。
- 留物清单支持选择藏身处已建等级，只统计未建等级要求战局中找到的材料；等价物品的任务与藏身处来源合并显示，收集数量和任务子目标双向同步。等级按本地记录和模式保存。
- 地图任务、非地图任务和留物清单显示物品小图，可点击放大查看，图片按可见内容加载。
- 多目标任务显示“子目标进度”按钮，支持保存部分数量、标记完成和清除手动记录，清单及地图任务数随之更新；单目标任务隐藏该按钮，已完成任务仍可通过任务名搜索的定位操作打开记录并撤销。
- “主线与 BTR”支持将当前任务或章节加入地图规划，并明确标记手动来源；可移出并保留子目标手记，也可打开对应攻略。
- “设置 → 更换游戏账号”可重置当前软件任务记录，按最新可明确归属账号及模式的日志重建。
- 侧栏“游戏时间”显示通用地图进图前相差12小时的两组时间。
- 对主资料缺录的任务，从 eftarkov.com 补充攻略与经核验的携带需求。
- PvE 二至六转“新起点”及“万圣节：危险地带”按真实任务 ID、模式和完整目标正文关联地图；地图页只展示相关目标，其他原文可展开查看，转生目标不混用。
- “设置 → 任务资料更新”独立更新补充任务、携带与攻略修正，验证发布签名后应用，无需更新 EXE。
- “设置 → 日志与数据自检”检查日志目录、模式、监听、资料版本和缺录任务。
- 打开对应任务攻略、按需查看位置文字与图片。
- 深色界面、窗口置顶与透明度调整、独立的游戏物理内存占用查看；物品大图、子目标进度和主线/BTR弹窗可拖动顶部标题栏移动。
- 默认窗口启动时按完整导航调整高度并限制在屏幕可用区域；较矮屏幕保留地图滚动，手动缩放后保持用户选择。

## 数据边界

工具依据本机日志已经记录的任务接取、完成和失败事件，不会登录游戏账号、检查背包或恢复缺失历史。现有日志不能可靠提供全部子目标进度，公开数据库刷新也不等于同步个人进度。准备勾选仅表示本局已自行核对物品。

任务悬浮窗仅在监听到新的开局时自动显示；加载途中启动工具可衔接此前完整的地图加载记录。局中重开后的历史计时恢复仅用于 BTR 预测，不会自动打开任务悬浮窗，也不能证明玩家仍在对局。建议游戏使用无边框或窗口化，普通桌面置顶窗口可能无法覆盖独占全屏。

BTR 显示的是完整参考底图上的路线和时刻表预测，不代表检测到本局车辆刷新或实时坐标。路线尚未确定时显示全部候选，目前没有自动识别本局实际线路的功能。自动计时需要同一对局完整且有效的日志记录，之后使用本地时钟继续倒计时；缺失时会明确提示，也可手动校准。暂停只暂停软件预测，继续后请核对游戏时间。“正在停靠”只能确定进度范围，未来行驶和停靠时长仍以参考模型推算。监听到匹配的返回大厅记录、新加载或日志上下文变化时清除旧计时与路线校正；关闭监听或缺少返回日志时，手动预测需自行清除。关闭任务悬浮窗不影响 BTR 日志识别。

跳蚤行情来自 tarkov.dev 的公开聚合采样，会有延迟，不保证游戏当前最低价或成交价。来源采样时间与本地获取时间分别显示；缺价不当作有效 0 卢布，网络失败时明确标记旧缓存。钥匙无法筛选满次数报价，静态最大使用次数不代表挂单剩余次数。收藏及报价缓存独立于任务记录；离开行情页或最小化时停止自动查询，恢复后按缓存有效期查询。本地 10 分钟查询间隔不代表上游每 10 分钟采样。

自检里的“最近任务事件”仅指本次运行实际解析到的日志事件，不以档案修改时间代替。路线顺序用于出发前准备，不保证地图之间可以直接转移；复杂任务条件保留原文供核对。

留物数量是软件本地手记，不读取仓库或提交游戏任务。物品ID及已核实的相同要求跨任务、藏身处合并，展开仍保留来源明细；数量与任务子目标双向同步，同一批寻找/上交不会重复累计。总需求、已收集及剩余统一计算，一个来源移除不会清零其他来源的记录；可选、替代组、任务专用品及额外限制不混算。未知条件保持隔离。未设置藏身处已建等级时按尚未建造计算；日志缺失的任务完成记录仍可能使清单多列需求。

手动子目标和主线/BTR规划只改变软件记录，不提交游戏任务，也不冒充日志同步。主线复合目标可能包含其他行动，材料备齐不会自动确认整个目标完成。主线目前收录已核验的PvE章节，其他模式不复制未经核验的主线资料；BTR按各模式真实商人资料识别。主线按明确地图的目标原文规划，物品收集与制作条件不一概视为提前携带，含分支章节请按游戏选择核对攻略，门票结局目标作为可选参考。未确定地图的目标保留原文；主线快照随程序维护，普通任务及藏身处资料可刷新数据库。

更换游戏账号后，先进入新账号主菜单，再在“设置 → 更换游戏账号”确认重置。重置不生成旧任务记录备份，旧留物数量和排序不再关联新记录；无法确认身份或写入失败时保留原主记录。日志不是完整任务快照，缺失历史及未记录子目标不会因重置补齐。旧格式记录在首次重置前沿用按模式导入，首次重置成功后，历史导入和持续监听均继续校验账号归属。

游戏时间按本机时钟计算，游戏未运行时也可显示，不是当前对局内时间。请保持系统时间正确；工厂等固定时间地图以游戏为准。

1.5.0 已移除独立 Boss 跟踪与档案切换入口。程序继续使用原先选中的本地记录，普通任务里的 Boss 击杀条件仍保留。

独立资料通过 `task-data` 预发布分发，客户端自动下载和验证，无需玩家手动安装。它不会改变程序稳定版的更新入口。下载失败时继续使用已有可信资料；位置图片按需从原攻略网站加载，物品图片按需从 tarkov.dev 公开素材站加载。

档案、偏好和缓存默认保存在 `%LOCALAPPDATA%\TarkovRaidPrep`。玩家分发包不包含作者的个人档案、日志或缓存。工具不向服务器上传游戏日志或任务进度；公开资料与更新检查会请求相应数据站点，程序和独立资料更新优先通过 gh-proxy.com 传输公开附件，必要时回退 GitHub。

手动“清理游戏内存”会整理游戏物理驻留工作集，可能引起卡顿；不会自动执行，与只读内存占用查看独立。
